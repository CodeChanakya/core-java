# Starter

This is the project you build in. The classes `Book`, `Member`, `Loan`, `Reservation`, `MemberType`,
`LibraryException`, `LibraryStore` and `InMemoryLibraryStore` are given and need no changes.

Your work is in two files:

- `LibraryService.java`: every method throws "TODO". Replace each with the real rule. The rules are in the Javadoc.
- `Main.java`: write a short demonstration of your own.

Also write your own tests in `src/test/java`, in classes whose names do not end in `AcceptanceTest`.

```
bash run.sh --compile   # does it compile?
bash run.sh --test      # run every test
bash run.sh --grade     # run only the acceptance tests and print your automatic score
```

Read the brief in [../README.md](../README.md) first and the [rubric](../RUBRIC.md) before you start.
