Personal Profile Generator

Beginner javac and java System.out Java 21 or newer

The problem

You want a program that introduces a person: it knows a few facts about them and prints those facts as a neat card in the terminal.

It is the smallest useful program in Java. Before you can build a bank or an online shop, you need to see one program go from a text file to something running.

See the flow

The whole program as one picture. Read it top to bottom; the colour of each card says what kind of step it is.

If you are new to coding

Like writing your name on a card and handing it to a printer: you write once, the computer prints it.

If you are learning

Follow the numbered cards from top to bottom. Open the file named on each card, run the program, and match its output to the last card.

If you are experienced

Source to bytecode to JVM is the same pipeline every later program uses. The file name must match the public class.

Text version of the flow
  1. Write the source file (input): PersonalProfile.java holds a few facts about a person.
  2. javac translates it (work): The compiler checks the spelling and makes bytecode (.class).
  3. The JVM runs the bytecode (work): java starts the Java Virtual Machine at main.
  4. main prints each line (work): System.out.println writes one line of text at a time.
  5. A neat card on screen (result): Name, age, city, role and what they are learning.

Read in this order

  1. 1PersonalProfile.javaThe whole program. Only about 15 lines do real work.
  2. 2expected-output.txtWhat a correct run prints.
  3. 3run.shThe two commands that compile and run it.

The code

src/main/java/PersonalProfile.java
/**
 * Prints a short personal profile to the console.
 *
 * This is the first program in the course, so it stays small on purpose:
 * store a few facts, then print them as a labelled card.
 */
public class PersonalProfile {

    public static void main(String[] args) {
        // Variables get a full lesson in Phase 2. For now, read each line as
        // "give this value a name". The word in front says what kind of value
        // it is: String is text, int is a whole number.
        String name = "Priya Nair";
        int age = 29;
        String city = "Pune";
        String role = "QA engineer";
        String learning = "Java";

        System.out.println("==============================");
        System.out.println("  PERSONAL PROFILE");
        System.out.println("==============================");
        System.out.println("Name     : " + name);
        System.out.println("Age      : " + age);
        System.out.println("City     : " + city);
        System.out.println("Role     : " + role);
        System.out.println("Learning : " + learning);
        System.out.println("==============================");
    }
}
