public class PersonalProfile {

    public static void main(String[] args) {
        // Read each line as "give this value a name".
        String name = "Priya Nair";
        int age = 29;
        String city = "Pune";

        System.out.println("Name     : " + name);
        System.out.println("Age      : " + age);
        System.out.println("City     : " + city);
    }
}

  2. 2Each line before the prints stores one fact under a name.
  3. 3Run ./run.sh --check and compare with expected-output.txt.
