# Solutions

One worked answer to every exercise, kept in the same folder layout as the program so you can compare file by file.

Everything is added to `Main.java` (B1 to B3 inline, then the helper methods `inCity`, `capAt` and `select` at the bottom). The new output appears under "Exercise answers".

Run the solution version:

```bash
./run.sh
```

Each change is marked with the exercise number in a comment, for example `// B1`. Your own answer can look different and still be right.
