# Solutions

`src/main` holds `Account.java` with the two methods added in exercises I1 and C1. `src/test` holds `AccountTest.java` with all the new tests; each is marked with its exercise number in its display name.

To try them, copy both files over your lab copy and run the tests:

```bash
cp -r src/main ../src/
cp -r src/test ../src/
cd .. && ./run.sh
```

Your own tests can look different and still be right. What matters is that each test fails when the behaviour it describes is broken.
