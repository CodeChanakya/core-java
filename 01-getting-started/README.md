# Phase 01 · Getting Started

One program. Its job is to get you from a text file to a running Java program, and to make the compiler's error messages familiar instead of frightening.

| No. | Program | New ideas |
|---|---|---|
| 01 | [Personal Profile Generator](01-personal-profile-generator) | `javac` and `java`, `System.out`, variables as labels |

## Mastery checkpoint

Without looking at the solution, write a program that prints a business card with your name, role, email and city. Then break it five different ways on purpose and read each error.

Move to Phase 2 when you can say, in your own words, what `javac` does, what `java` does, and why the class name must match the file name.
